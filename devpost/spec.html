Cadence

A local Python app for learning progressions, training and testing a small chord model, and exporting printable song charts.

How this works, in plain language

Your five original songs and chord labels teach a small classifier to connect audio pitch patterns with chord names. A command-line training run uses four songs to train, compares the new model with the old template analyzer on a fifth song, then saves the trained model. Visitors do not train; the local app loads that saved model.

The app analyzes a visitor's local audio, shows chord and musical-detail estimates, lets them correct the chart information and mark song sections, and creates a downloadable PDF. It also has the searchable progression library and theory lessons. The app never sends visitor audio to a remote service.

Five songs make a useful experiment, not a guarantee of accuracy on unfamiliar music. The held-out comparison may show that the trained model does not improve on the old analyzer.

Components and their jobs

Learning library — `app.py`, `data/progressions.json`, `theory.py`, `audio_examples.py`

Streamlit shows the experience choice, optional major-scale tutorial, searchable/filterable progression cards, theory lessons, and original synthetic WAV examples.

Implements `prd.md > Experience choice and beginner tutorial`, `Searching and browsing the progression databank`, and `Understanding and hearing a progression`.

Training run — `training.py`, `audio_features.py`, `annotations.csv`, `split.json`

A timed annotation row pairs a song and audio interval with a chord label. The training command turns each interval into pitch-summary examples, fits a small classifier on four complete songs, tests both methods against a held-out fifth song on the same labeled audio frames, reports accuracy and macro-F1, and saves the trained model.

The label set is 24 major/minor triads, no-chord, Daug, and Eaug. Seventh/sixth chords are simplified to same-root major/minor triads, and slash-chord bass inversions are ignored. Daug and Eaug appear only in Demo 5, which stays in training, so their cross-song performance cannot be evaluated on the held-out song. Other qualities remain outside this experiment.

The existing /models/ ignore rule stays in place; only the approved public classifier artifact is allow-listed.

Implements `prd.md > Training and evaluating the chord model`.

Local song analysis — `chord_model.py`, `song_metadata.py`, `matching.py`

The app loads the saved model, predicts chord labels from visitor audio, estimates key and tempo, and suggests a common time signature. Metadata and chord results are estimates; visitors can correct key, tempo, and meter. Song sections are manually marked by bar range.

Audio stays local. A plausible progression can link to a library lesson; weak or unmatched results do not force a link.

Implements `prd.md > Analyzing a local song`.

Printable chart — `chart_pdf.py`

ReportLab creates the PDF in memory. It includes title, corrected key/tempo/time signature, user-marked sections, numbered bars, beat dots, chord labels, and an estimate disclaimer. Streamlit provides the download.

Implements `prd.md > Exporting a performance chart`.

Tests — `tests/`

Use synthetic features/audio and small test annotation tables to verify parsing, song-level splits, training, baseline comparison, metadata uncertainty, chart layout, pattern matching, and existing behavior. Do not make automated tests depend on the learner's recordings.

Covers acceptance criteria across `prd.md > Features and Behavior`.

Tools and where they run

  • Python 3.12 + Streamlit: local browser app; Streamlit docs.
  • librosa: audio features, beat/tempo estimate; librosa docs.
  • scikit-learn: small supervised classifier; scikit-learn docs.
  • joblib: save and load the local model; joblib docs.
  • ReportLab: downloadable PDF generation; ReportLab docs.
  • NumPy/SciPy: local numeric and signal helpers; NumPy · SciPy.
  • No API keys, hosted model, cloud service, or remote audio path.

Install/update from the project root:

.venv\Scripts\python.exe -m pip install -e .

Run training and evaluation first, then start the app:

.venv\Scripts\python.exe -m cadence.training
.venv\Scripts\python.exe -m streamlit run app.py

Open the browser tab Streamlit starts or visit http://localhost:8501. The training command prints the held-out comparison and saves models\chord_classifier.joblib.

What stays small

  • One local app, no separate API or hosted service.
  • Five original songs, one song held out; no general-accuracy claim.
  • 24 major/minor chord labels, Daug/Eaug, and no-chord; augmented labels are represented by one song.
  • Manual timed label table and section boundaries; no PDF-reading or structure-detection model.
  • Heuristic metadata suggestions with user correction.

If something goes wrong

  • Bad labels/audio stop training with a specific row/file error.
  • Missing model tells the owner to run the training command.
  • Unsupported audio or uncertain meter prompts a clear correction or retry.
  • PDF failure leaves valid on-screen analysis intact.
  • No match means no unrelated lesson link.
