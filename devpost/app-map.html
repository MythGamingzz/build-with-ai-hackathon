Cadence — App Map

A music-theory learning app with a local chord-analysis experiment.

Local processing: song analysis runs on this computer. Use only audio you own or are authorized to analyze; Cadence does not send recordings to a service.

How the pieces fit

A visitor supplies a local recording and marks song sections. Cadence estimates chord events, finds exact catalog progression candidates within each section, then shows colored candidate links in the interactive chart. The chart PDF uses the same confirmed bar-and-beat data but stays plain, without progression highlights.

Reference route: one candidate to its lesson

Follow one matched chord from the data the app retains to the link a visitor sees.

  1. src/cadence/matching.py — search for ProgressionCandidate and match_progression. The matcher retains each exact progression, its key, and the event positions that matched.
  2. app.py — follow _render_chart_group to _matched_chord_html. These functions map candidates to chord cells, blend shared colors, and put a separate lesson link beneath every candidate in the hover/focus card.
  3. tests/test_chart_ui.py — find test_shared_match_blends_colors_and_links_each_candidate. It checks the blended highlight and verifies that each candidate has its own lesson link without assigning one lesson to the shared chord.

To change this, start here

  • Change which progression patterns match: src/cadence/matching.py, starting at match_progression.
  • Change candidate positions or section-grouped chart data: src/cadence/chart_data.py, starting at build_chart_data.
  • Change chart colors, hover details, or lesson links: app.py, starting at _matched_chord_html and _render_chart_group.
  • Change the printed layout while keeping it plain: src/cadence/chart_pdf.py, starting at _MeasureRow and create_chart_pdf. tests/test_chart_pdf.py checks that matched chords are not highlighted.

A practice to reuse

The requirement was that a shared chord show every exact candidate, with a separate lesson link for each instead of silently choosing one. tests/test_chart_ui.py checks that visible output shape, and the running app confirmed the link opens the matching lesson. On another project, make a user-facing requirement measurable in a test, then try the result in the real interface.

Run it again

From the project folder, start the local app:

.\.venv\Scripts\python.exe -m streamlit run app.py

Open the browser tab Streamlit provides, or navigate to http://localhost:8501. Select only an authorized local audio file for analysis.
